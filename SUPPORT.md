# Getting help

| You want to… | Go to |
|---|---|
| Understand why a message ran on a model | Click the gear pill in that thread, or run `bb gearshift explain "<text>"`. The [routing policy guide](docs/routing-policy.md) explains every signal. |
| Change what Gearshift does | **Settings → Plugins → Gearshift**; see the [tuning recipes](docs/routing-policy.md#tuning-recipes). |
| Ask a question or share a setup | [GitHub Discussions](https://github.com/vanZeben/bb-gearshift/discussions) |
| Report a routing decision that looks wrong | [Open a "Routing decision" issue](https://github.com/vanZeben/bb-gearshift/issues/new/choose) |
| Report a bug | [Open a bug report](https://github.com/vanZeben/bb-gearshift/issues/new/choose) |
| Report a security problem | Privately, as [SECURITY.md](SECURITY.md) describes |
| Get help with bb itself | [getbb.app](https://getbb.app) |

Gearshift is maintained in spare time, so answers can take a few days. If it's useful to you,
[sponsoring its development](https://github.com/sponsors/vanZeben) helps keep it going.
